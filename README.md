# UNIUNI01A - Universal module PCB

![UNIUNI01A](/doc/img/UNIUNI01A_PCB.png)

### Description

A platform for soldering testing circuits. This universal PCB, often referred to as a Veroboard or Perfboard, is compatible with the MLAB kit. It is designed for general-purpose soldering applications, providing a flexible and convenient base for constructing various electronic circuits.

### Features

- Universal design for various electronic constructions
- Compatible with MLAB kits
- Ideal for prototyping and testing circuits

### Usage

This board can be used in a wide range of applications, from simple hobby projects to more complex electronic prototypes. The PCB's universal layout allows for easy modification and expansion, making it a valuable tool for both beginners and experienced electronics enthusiasts.
